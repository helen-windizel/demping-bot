## Для резюме (готовые материалы)

| Файл / папка | Описание |
|--------------|----------|
| `Demping-Bot-Portfolio.pdf` | **Один PDF** со всеми ключевыми экранами (~1.2 MB) |
| `compressed/` | Сжатые JPG-версии (28.9 MB → 1.2 MB) |

Рекомендуется прикрепить к резюме **PDF** — он лёгкий и открывается везде.

## Обновить скриншоты и PDF

```bash
npm run dev
# в другом терминале:
npm run screenshots
npm run portfolio
```
